</Note>

The HFSAA Public API makes HFSAA-approved directory data available for use in third-party applications.

## What the API includes

- HFSAA-certified restaurants
- HFSAA-certified meat markets
- HFSAA-certified dining halls
- HFSAA chapter information and an official per-location verification URL
- An optional Google Place ID for developers who choose to enrich their own views through Google Places

## Attribution is required

When you display HFSAA location data in a user-facing product, visibly attribute HFSAA. The attribution for each displayed location must link to that location’s `verification_url`, so users can verify the listing on HFSAA’s official locator.

## What the API does not include

- Certificate IDs or certificate dates
- Google photos, photo URLs, Google Maps URLs, or Google-derived business details
- Contact names, contact emails, or internal operational data
- Write endpoints

## Production base URL

`https://api.hfsaa.org`
